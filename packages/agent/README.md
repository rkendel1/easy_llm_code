# @easy-llm/code-agent

The npm distribution of **easy-llm-code**, a project-aware coding agent with persistent local memory, sandboxed execution, IDE integration, and provider-neutral model routing.

```sh
npm install -g @easy-llm/code-agent
cd your-project
easy-llm-code
```

The package also retains `llm-code` as a temporary compatibility alias. Native installers are the recommended end-user distribution path.
